# Worktime — учёт рабочего времени

Код приложения находится в папке **Worktime Tracker**.

## Запуск

Нужен Python 3.11+. Установка Python-пакетов и сборка основного интерфейса не требуются.

```bash
cd "Worktime Tracker"
python3 app.py --demo
```

Откройте http://127.0.0.1:8765. Демо: `admin` / `admin-demo-2026` (администратор), `anna` / `anna-demo-2026` (сотрудник). Все данные вымышлены.

Есть создание сотрудников, таймер с описанием задачи, отчёты за период и сохранение в SQLite. Дополнительно: две роли, расширение Chrome для статистики активной вкладки и простоя, светлая/тёмная тема.

## ИИ и исправления

Код подготовлен с OpenAI Codex; в среде указано семейство GPT-6, точный ID модели не предоставлен. Примеры запросов: «Создайте с нуля небольшое веб-приложение для учёта рабочего времени», «Предусмотри разные роли создание новых сотрудников», «Примени тему». Полные примеры и объяснения — в README приложения.

Исправлены потеря очереди при переподключении расширения, влияние старого ответа сервера на новый вход, остаточные данные после выхода, неверные границы активности при переводе часов и HTTP 500 на некорректных идентификаторах.

Локально прошёл 61 Python-тест и 36 JavaScript-проверок, включая настройки HTTPS и деморежима. Запуск в настоящем браузере и загрузка расширения в среде подготовки не проверены. GitHub Actions проверяет Python, JavaScript, React и Docker/HTTP-сценарий; его результат нужно смотреть отдельно.

## Проверки

```bash
cd "Worktime Tracker"
python3 -m unittest discover -v
```

С Node.js: `npm test`. React: `npm install` и `npm run build` внутри папки приложения. Основной интерфейс не требует Node.js.
