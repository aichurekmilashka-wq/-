По дополнительным запросам добавлены настоящий вход, две роли и создание сотрудников; права проверены серверными тестами. Расширение и React-сетка относятся к расширенному объёму: логика расширения проверена автоматически, но установка в Chrome, React-сборка и визуальная работа остаются непроверенными из-за ограничений среды.

## Исправлено при этом аудите

1. Повторное подключение расширения очищало неотправленные события. Теперь прежнее подключение сохраняет очередь; смена сотрудника с незавершённой доставкой не удаляет её молча. Возобновление после паузы не добавляет время паузы.
2. Запоздавший ответ 401 от предыдущего входа очищал интерфейс нового пользователя. Ответы привязаны к поколению входа; старый ответ не переключает новую сессию.
3. При выходе оставались описание задачи, имя аккаунта, список выбора сотрудников и пароль из незавершённой формы создания сотрудника. Теперь эти поля очищаются.
4. Слишком большие идентификаторы сотрудников/задач вызывали OverflowError SQLite и HTTP 500. Теперь возвращается корректный HTTP 400, включая маршрут остановки.
5. После перевода часов назад в отчёте могла оставаться страница с нулевым пересечением с задачей. Такие страницы теперь исключены.

Все перечисленные ошибки воспроизведены проверками до исправлений. Итоговый `sh scripts/check.sh`: **54 Python-теста + 19 проверок расширения + 13 проверок интерфейса**, все успешны. Синтаксис четырёх JavaScript-файлов также проверен.

## Вывод

Основные функции исходного ТЗ подтверждены кодом и автоматическими проверками. Полную готовность к сдаче нельзя подтвердить без запуска в браузере. Публичная ссылка на репозиторий уже есть. Для расширенного варианта дополнительно нужны фактическая установка расширения в Chrome и сборка React на машине с Node.js. Эти ограничения не скрыты в README и verification.md.
