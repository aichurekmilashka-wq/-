# Учёт рабочего времени: решение

Цель — небольшое запускаемое локально веб-приложение для тестового задания.
Публикацию пользователь выполняет самостоятельно. Проект передаётся папкой и ZIP на рабочем столе.

## Состав

- Python 3.11+, стандартная библиотека: WSGI, SQLite, unittest. Установка пакетов не требуется.
- HTML/CSS/JavaScript без сборки; русский интерфейс.
- По дополнительному запросу: тема из предоставленного примера, React/TypeScript/Tailwind/shadcn-совместимая сборка Motion-виджетов; основной интерфейс доступен и без неё.
- Расширение Chrome Manifest V3, Chrome 120+, с разрешениями tabs, idle, alarms, storage и доступом только к локальному API.
- SQLite хранит сотрудников, пользователей, сессии входа, задачи, интервалы активности. Данные исключены из Git и архива.

## Роли и вход

Администратор создаёт сотрудников с логином и паролем, запускает/останавливает задачи и видит все отчёты.
Сотрудник запускает/останавливает только свои задачи и видит только свои записи и код расширения.
Права проверяются сервером. Пароли — PBKDF2-SHA256 с индивидуальной солью.
Сессия входа — случайный токен в HttpOnly/SameSite cookie, 12 часов, в БД хранится его SHA256.
Демо создаётся явным флагом --demo и содержит только вымышленные данные.

## Таймер и отчёты

Один активный таймер на сотрудника обеспечивается уникальным индексом SQLite, включая одновременные запросы.
Начало и конец берутся по серверным часам. Повторная остановка сохраняет первоначальное окончание.
Активная задача переживает перезапуск; её общее время включает период отсутствия приложения.
Период отчёта задаётся датами UTC включительно, время пересекающей границу задачи обрезается по периоду.
Пустой отчёт показывает 0, включая сотрудников без задач.

## Наблюдение браузера

Расширение привязывается к сотруднику случайным кодом. Оно наблюдает только при запущенной задаче.
Каждые 30 секунд и при изменении вкладки/фокуса/простоя отправляет предыдущий интервал:
page (активная вкладка в окне на переднем плане), idle (простой или блокировка), away (остальные приложения/служебные вкладки).
Порог простоя — 5 минут: это правило наблюдения, а не доказательство отсутствия работы.
Приватные вкладки не учитываются. URL очищается от параметров, фрагмента и учётных данных; сохраняется заголовок до 200 символов.
Содержимое страниц, нажатые клавиши и снимки экрана не собираются.
Категории сайтов определяются открытыми правилами, оценка продуктивности не вычисляется.

События имеют уникальный ID, повторная отправка не удваивает время. Интервалы обрезаются по границам задачи и предыдущему событию.
Перерыв между наблюдениями более 90 секунд не приписывается последней странице; он остаётся «без наблюдения».
В отчёте общее время задачи равно сумме страниц, простоя, других приложений и времени без наблюдения.
Расширение хранит небольшую очередь неотправленных событий; при отсутствии сервера новые наблюдения не выдумываются.
Остановка задачи может дать до 30 секунд ненаблюдённого хвоста до следующего опроса; это явно указано в README.

## Проверка и пределы

unittest проверяет хранение, интервалы, повторные запросы, доступ по ролям и HTTP-контракт через WSGI.
Чистая логика расширения проверяется JavaScript-тестами в Node.js либо JavaScriptCore.
Финальная проверка браузера/загрузки расширения зависит от доступного браузера; непроведённые проверки отмечаются честно.
Встроенный WSGI-сервер предназначен для локального тестового, а не публичного размещения.
